Local demo draft — not ready for publication. This notice describes the current replay demo. It needs channel contact details, confirmed retention controls, and a review against Twitch's terms before use with a live channel.

What the demo uses

Regulars stores replayed chat messages and viewer identifiers in a local database to organize conversations, check blocked topics, and create awards. The private dashboard can show messages, presence records, and nudges. The public crew page and overlay show approved stickers, contributor names, and awards. They do not show chat quotes or private presence information.

When configured, OpenRouter processes chat text for classification and summaries. Sticker image generation uses OpenAI when a separate image API key is configured. Without those keys, the demo uses offline classification and cannot create sticker images.

Storage and deletion

The current demo does not automatically delete chat text after 24 hours. A dashboard operator can delete channel data or forget a viewer by Twitch user ID. The !regulars forget command is handled for messages ingested by the demo, but live Twitch chat is not connected yet.

Before a live channel

Publish a channel-specific notice with an operator contact, verified retention periods, and the AI providers in use. Confirm the live opt-out and deletion flows before enabling live ingestion.
